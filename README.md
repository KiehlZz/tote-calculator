# เครื่องคิดเลขโต๊ด

เว็บแอป (PWA) สำหรับคำนวณเลขโต๊ด 3 หลัก ใช้บน iPad และ Android Tablet ได้โดยไม่ต้องต่ออินเทอร์เน็ตหลังเปิดครั้งแรก ข้อมูลทั้งหมดเก็บในเครื่องของผู้ใช้ ไม่มีเซิร์ฟเวอร์และไม่ส่งข้อมูลไปที่ใด

## กติกาการคำนวณ

- เลข 3 หลักที่ประกอบด้วยตัวเลขชุดเดียวกัน แม้สลับตำแหน่ง ถือเป็นกลุ่มเดียวกัน เลขตัวแทนคือเรียงตัวเลขจากน้อยไปมาก เช่น 321 → 123
- มี 6 คอลัมน์ตายตัว: x30, x60, x120, x150, x180, x210
- ผลรวมของแต่ละกลุ่ม = ผลบวกค่าตัวคูณของทุกรายการที่กรอก เลขซ้ำนับทุกครั้ง ไม่ตัดซ้ำ
- เรียงผลลัพธ์ตามผลรวมมากไปน้อย ถ้าเท่ากันเรียงเลขตัวแทนน้อยไปมาก
- ข้อมูลอยู่ในเบราว์เซอร์ของแต่ละเครื่อง ควรสำรองเป็นไฟล์ JSON จากปุ่ม "สำรองข้อมูล" เป็นระยะ

## การพัฒนา

ต้องใช้ Node.js 22 (ที่ใช้พัฒนาคือ 22.19)

```text
npm install
npm run dev          เปิดโหมดพัฒนา
npm test             รันเทสต์ทั้งหมด
npm run build        build ปกติ
npm run check:pages  ตรวจทั้งชุดสำหรับ GitHub Pages (เทสต์ + build ใต้พาธ /tote-calculator/ + ตรวจ precache และ base)
```

เทคโนโลยี: TypeScript, Vite, Dexie (IndexedDB), vite-plugin-pwa, Vitest
