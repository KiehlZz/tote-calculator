# เครื่องคิดเลขโต๊ด
เปิดใช้งาน: https://kiehlzz.github.io/tote-calculator/

คู่มือใช้งาน: [docs/USER_GUIDE.md](docs/USER_GUIDE.md) · บันทึกการเปลี่ยนแปลง: [CHANGELOG.md](docs/CHANGELOG.md)

เว็บแอป (PWA) สำหรับคำนวณเลขโต๊ด 3 หลักและ 4 หลัก ใช้บน iPad และ Android Tablet ได้โดยไม่ต้องต่ออินเทอร์เน็ตหลังเปิดครั้งแรก ข้อมูลทั้งหมดเก็บในเครื่องของผู้ใช้ ไม่มีเซิร์ฟเวอร์และไม่ส่งข้อมูลไปที่ใด

## กติกาการคำนวณ

- แต่ละชุดข้อมูลเป็นแบบ 3 ตัว หรือ 4 ตัว อย่างใดอย่างหนึ่ง เลือกตอนสร้างชุด และเปลี่ยนภายหลังไม่ได้
- เลขที่ประกอบด้วยตัวเลขชุดเดียวกัน แม้สลับตำแหน่ง ถือเป็นกลุ่มเดียวกัน เลขตัวแทนคือเรียงตัวเลขจากน้อยไปมาก เช่น 321 → 123 (3 ตัว) และ 4321 → 1234 (4 ตัว)
- ชุด 3 ตัว: เลข 3 หลัก มี 6 คอลัมน์ตายตัว x15, x30, x60, x120, x150, x180
- ชุด 4 ตัว: เลข 4 หลัก มี 2 คอลัมน์ตายตัว x24, x48
- ผลรวมของแต่ละกลุ่ม = ผลบวกค่าตัวคูณของทุกรายการที่กรอก เลขซ้ำนับทุกครั้ง ไม่ตัดซ้ำ
- เรียงผลลัพธ์ตามผลรวมมากไปน้อย ถ้าเท่ากันเรียงเลขตัวแทนน้อยไปมาก
- ข้อมูลอยู่ในเบราว์เซอร์ของแต่ละเครื่อง ควรสำรองเป็นไฟล์ JSON จากปุ่ม "สำรองข้อมูล" เป็นระยะ

## การพัฒนา

ต้องใช้ Node.js 22 (ที่ใช้พัฒนาคือ 22.19)

```text
npm install
npm run dev          เปิดโหมดพัฒนา
npm test             รันเทสต์ทั้งหมด
npm run build        build ปกติ
npm run check:pages  ตรวจทั้งชุดสำหรับ GitHub Pages (เทสต์ + build ใต้พาธ /tote-calculator/ + ตรวจ precache และ base)
```

เทคโนโลยี: TypeScript, Vite, Dexie (IndexedDB), vite-plugin-pwa, Vitest
