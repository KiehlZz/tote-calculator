# บันทึกการเปลี่ยนแปลง

## 1.2.0 (11 พ.ย. 2569)

- เพิ่มชุดข้อมูลแบบ 4 ตัว: กดปุ่ม "สร้างชุด 4 ตัว" ที่หน้าหลัก กรอกเลข 4 หลักในคอลัมน์ x24 และ x48 ผลลัพธ์แสดงด้านขวาเหมือนชุด 3 ตัว (4321 กับ 1234 รวมเป็นกลุ่มเดียวกัน)
- ชุดข้อมูลแต่ละชุดเป็น 3 ตัวหรือ 4 ตัว อย่างใดอย่างหนึ่ง เปลี่ยนภายหลังไม่ได้ หน้าหลักมีป้ายบอกแต่ละชุด ชุดเดิมทั้งหมดเป็นชุด 3 ตัวและใช้งานได้ตามเดิม
- ไฟล์สำรองเก็บประเภทของชุดด้วย ไฟล์สำรองเก่าทุกไฟล์ยังกู้คืนได้ (เป็นชุด 3 ตัว) ไฟล์ที่มีชุด 4 ตัว กู้คืนเข้าเวอร์ชันเก่ากว่า 1.2.0 ไม่ได้
- แนะนำให้สำรองข้อมูลก่อนอัปเดต เพราะเวอร์ชันนี้ปรับโครงสร้างข้อมูลในเครื่อง ข้อมูลเดิมไม่หาย แต่ย้อนกลับไปเวอร์ชันเก่าไม่ได้

## 1.1.0 (9 พ.ย. 2569)

- เปลี่ยนคอลัมน์เป็น x15, x30, x60, x120, x150, x180 (เพิ่ม x15 และเลิกใช้ x210)
- ข้อมูลเดิมในคอลัมน์ x210 ต้องลบก่อนใช้งานต่อ แอปถามยืนยัน และเก็บไฟล์ไว้ดูได้ก่อนลบ ไฟล์สำรองเก่าที่มี x210 กู้คืนไม่ได้

## 1.0.0 (8 พ.ย. 2569)

เวอร์ชันแรก

- สร้างชุดข้อมูล กรอกเลข 3 หลักใน 6 คอลัมน์ (x30, x60, x120, x150, x180, x210) แก้ไขและลบได้ บันทึกอัตโนมัติ
- รวมเลขโต๊ดและตัวคูณตามกติกา นับเลขซ้ำทุกครั้ง รักษาเลขที่ขึ้นต้นด้วย 0
- สำรองและกู้คืนข้อมูลเป็นไฟล์ JSON (เพิ่มเข้าไปหรือแทนที่ทั้งหมด)
- ใช้งานออฟไลน์ได้ ติดตั้งลงหน้าจอโฮมได้ มีแถบแจ้งเมื่อมีเวอร์ชันใหม่

ข้อจำกัดที่ทราบ

- ข้อมูลอยู่ในเครื่อง ไม่ซิงก์ระหว่างเครื่อง ต้องสำรองเป็นระยะ
- เปิดครั้งแรกต้องมีอินเทอร์เน็ต
- ทดสอบแล้วบน Chrome (Windows) และ Safari บน iPad Gen 9 (iPadOS 26) ติดตั้งจากหน้าจอโฮม ยังไม่ได้ยืนยันบน Android
