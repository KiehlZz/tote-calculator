# คู่มือการใช้งาน เครื่องคิดเลขโต๊ด

## ติดตั้ง (ทำครั้งเดียว)

ต้องต่ออินเทอร์เน็ตในครั้งแรกเท่านั้น

1. เปิดลิงก์ https://kiehlzz.github.io/tote-calculator/
2. รอจนเห็นแถบดำด้านล่างเขียนว่า "พร้อมใช้งานออฟไลน์แล้ว" แล้วกด "ตกลง"
3. เพิ่มแอปลงหน้าจอโฮม
   - **iPad (Safari):** แตะปุ่มแชร์ แล้วเลือก "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)
   - **Android (Chrome):** แตะเมนู ⋮ แล้วเลือก "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก" (ชื่อเมนูอาจต่างกันเล็กน้อยตามรุ่น)
4. เปิดแอปจากไอคอนบนหน้าจอโฮมทุกครั้ง (ไม่ใช่จากแท็บของเบราว์เซอร์) หลังติดตั้งแล้วใช้งานได้โดยไม่ต้องต่ออินเทอร์เน็ต

## วิธีใช้

1. หน้าหลัก กด "สร้างชุดข้อมูลใหม่" เพื่อสร้างชุดเลข 3 ตัว หรือกด "สร้างชุด 4 ตัว" เพื่อสร้างชุดเลข 4 ตัว แล้วตั้งชื่ออะไรก็ได้ เช่น รอบเช้า (ชุดหนึ่งเป็นได้แบบเดียว เปลี่ยนภายหลังไม่ได้ ป้าย "3 ตัว" หรือ "4 ตัว" บอกประเภทของแต่ละชุด)
2. กรอกเลขลงในคอลัมน์ ชุด 3 ตัว กรอกเลข 3 หลักในคอลัมน์ x15, x30, x60, x120, x150, x180 ชุด 4 ตัว กรอกเลข 4 หลักในคอลัมน์ x24, x48 พิมพ์ครบจำนวนหลักระบบเพิ่มให้เอง และช่องจะว่างเพื่อกรอกเลขถัดไป เลขซ้ำนับทุกครั้ง
3. แตะเลขในรายการเพื่อแก้ไขหรือลบ
4. ผลลัพธ์อยู่ด้านขวา (หรือด้านล่างถ้าจอแนวตั้ง) เลขที่ใช้ตัวเลขชุดเดียวกัน (แม้สลับตำแหน่ง) รวมเป็นกลุ่มเดียว แสดงเลขตัวแทน (เรียงตัวเลขจากน้อยไปมาก เช่น 321 เป็น 123 หรือ 4321 เป็น 1234) ผลรวมของตัวคูณ และจำนวนรายการ เรียงจากผลรวมมากไปน้อย
5. บันทึกอัตโนมัติทุกครั้ง ไม่มีปุ่มบันทึก

## สำรองและกู้คืนข้อมูล (สำคัญ)

ไฟล์สำรองเก็บทั้งชุด 3 ตัวและชุด 4 ตัว ไฟล์สำรองเก่าจากเวอร์ชันก่อนหน้ากู้คืนเข้าเวอร์ชัน 1.2.0 ได้ (เป็นชุด 3 ตัว) แต่ไฟล์ที่มีชุด 4 ตัวกู้คืนเข้าเวอร์ชันเก่ากว่า 1.2.0 ไม่ได้ ก่อนอัปเดตเป็นเวอร์ชัน 1.2.0 ควรกด "สำรองข้อมูล" ไว้ก่อน

ไฟล์สำรองจากเวอร์ชัน 1.0.0 ที่มีเลขในคอลัมน์ x210 กู้คืนเข้าเวอร์ชัน 1.1.0 ไม่ได้ ถ้าเปิดแอปแล้วขึ้นหน้าต่างเรื่องคอลัมน์ที่เลิกใช้ ให้เลือก 'เก็บไฟล์ไว้ดู' ถ้าอยากเก็บข้อมูลเดิม แล้วจึงเลือก 'ลบรายการ

ข้อมูลเก็บอยู่ในเครื่องนี้เท่านั้น ไม่ส่งไปที่ไหนและไม่ซิงก์ระหว่างเครื่อง ถ้าลบแอป ล้างข้อมูลเว็บไซต์ หรือเปลี่ยนเครื่อง ข้อมูลจะหาย จึงควรสำรองเป็นระยะ


- **สำรอง:** หน้าหลัก กด "สำรองข้อมูล" แล้วเลือกบันทึกเป็นไฟล์ (iPad: "บันทึกไปยังไฟล์") เก็บไฟล์ `.json` ไว้ในที่ปลอดภัย
- **กู้คืน:** กด "กู้คืนข้อมูล" เลือกไฟล์สำรอง แล้วเลือก
  - "เพิ่มเข้าไป" ข้อมูลเดิมในเครื่องยังอยู่ และเพิ่มชุดจากไฟล์เข้ามา
  - "แทนที่ทั้งหมด" ลบข้อมูลเดิมทั้งหมดแล้วใช้ข้อมูลจากไฟล์แทน (ระบบถามยืนยันอีกครั้ง)

## เมื่อมีเวอร์ชันใหม่

จะมีแถบดำเขียนว่า "มีเวอร์ชันใหม่ของแอป" กด "อัปเดตตอนนี้" หน้าจะโหลดใหม่ (เลขที่ยังพิมพ์ไม่ครบจำนวนหลักจะหายไป ข้อมูลที่บันทึกแล้วไม่หาย) หรือกด "ไว้ทีหลัง" เลขเวอร์ชันอยู่ท้ายหน้าหลัก

## ปัญหาที่พบบ่อย

- เปิดแอปครั้งแรกไม่ได้: ต้องต่ออินเทอร์เน็ตในครั้งแรก
- ข้อมูลหาย: กู้คืนจากไฟล์สำรองล่าสุด
- แจ้งปัญหา: บอกเลขเวอร์ชัน รุ่นอุปกรณ์ และสิ่งที่ทำก่อนเกิดปัญหา
